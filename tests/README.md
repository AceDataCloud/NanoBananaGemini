# Nano Banana runtime checks

`python3 -m unittest discover -s tests` is ordinary test discovery. Run `smoke_extension.py --cli /absolute/gemini.js --output /tmp/check.json` for isolated native install/password/secret/list/Skill/check-command and fixture-only original task lookup. The fixture task ID is never sent to the hosted service.

For live information/discovery, export an existing authorized Key as `ACEDATACLOUD_SERVICE_TEST_TOKEN` and add `--live-info`. Run `/nano-banana-check` inside Gemini CLI. It only describes names/schemas already loaded; **Nano Banana has no static reference tool, so no media or task tool is called**. Your configured main model can still charge for inference. A real task lookup requires your own authorized existing ID; do not use a made-up ID. The model is still deterministic localhost; no new paid media or model request. Only local fixtures can use test IDs.

CI also runs `smoke_remote_install.py` against the actual published review commit, without a Key, to prove native GitHub source resolution/list/removal. Credentials are never passed in process arguments or committed evidence.
